This is an accounting ledger application that allows users to keep track of deposits and payments they have made or recieved. 
this application also lets you view these files by utilizing the ledger and report screen. You have the option to view all transactions and the report screen has more specific viewing options.
If you should accidentally type something that the code cannot understand, it will default you to an iconic movie quote. The game is to guess what movie it came from.
Movie quotes will also show up when you go back to a page or exit the program all together. If you can guess them all, that means you are quite the movie buff.
